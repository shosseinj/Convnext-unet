# User/author inputs required before final DOCX

These fields cannot be inferred from the repository or experimental evidence and must not be fabricated.

1. Author names, in publication order.
2. Affiliation text and the author-to-affiliation mapping.
3. Corresponding-author name and email address.
4. Code/archive URL and any access or release conditions. If no public release is planned, approve the exact alternative availability statement.
5. CRediT-style contribution roles for each author: conceptualization, methodology, software, validation, formal analysis, original drafting, review/editing, and supervision.

DOCX targets: body paragraphs 1-3, 279, and 285 in `reports/docx_target_paragraphs.json`.

Status: `USER_REQUIRED`. These fields do not block training, evaluation, aggregation, or preparation of evidence-backed manuscript sections, but they block final placeholder-free DOCX approval.
