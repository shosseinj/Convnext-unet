# Word Update Contract

هر مرحله‌ای که به تکمیل مقاله کمک می‌کند باید یک بسته Word-ready تحویل دهد.

- Stage:
- Section or table/figure number:
- Exact insertion location:
- Final prose text:
- Equations or symbols changed:
- Table CSV:
- Table LaTeX:
- Figure file:
- Figure caption:
- Source/evidence files:
- Dataset/split/checkpoint:
- Seed aggregation:
- Reviewer status:
- Open placeholders:

قواعد:

1. عدد بدون evidence manifest وارد Word نشود.
2. جدول نهایی mean±std یا دلیل شفاف نبودن آن را داشته باشد.
3. هر شکل caption، legend، color map و روش تولید داشته باشد.
4. قبل از replace Word، backup گرفته شود.
5. پس از replace، DOCX render و صفحه‌های تغییرکرده بررسی شوند.
6. نام رسمی فقط BSEI است؛ نام‌های قدیمی در متن نهایی باقی نمانند.
